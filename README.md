# byo-redis

A Redis clone built from scratch in C++ — event loop, custom hashtable with incremental resizing,
AVL-based sorted sets, TTL heap, and thread pool.

Built following *Build Your Own Redis with C/C++* (build-your-own.org/redis), with extensions
beyond the book for interview differentiation.

## Build

```bash
cd src
mingw32-make
```
